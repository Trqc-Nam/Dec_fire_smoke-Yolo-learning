# Fire & Smoke Detection with YOLO

A personal learning project on object detection using YOLO to detect **fire** and **smoke** in images.

## About

This project was created to practice a complete computer vision workflow, from dataset preparation to model training and evaluation.

The datasets used in this project are publicly available and pre-labeled.

## What I Did

* Combined datasets from different sources
* Removed duplicate images
* Standardized class labels
* Prepared the dataset for YOLO
* Trained and evaluated a YOLO model
* Analyzed the training results

## Tools

* Python
* YOLO
* PyTorch
* OpenCV
* Kaggle

## Project Purpose

This is a **personal learning project**, not a research project or a competition entry.

The main goal was to gain hands-on experience with data preprocessing, object detection, model training, and evaluation.
